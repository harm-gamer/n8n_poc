# 📧 AI-Powered Email Processing Automation using n8n, Ollama, MongoDB & Slack

## 📌 Project Overview

This project demonstrates a complete AI-powered workflow automation pipeline built using **n8n**, **Ollama (Qwen3)**, **Node.js**, **Express.js**, **MongoDB**, and **Slack**.

The system automatically monitors incoming emails, extracts meaningful information using a local Large Language Model (LLM), stores the processed data in MongoDB, and notifies the team through Slack.

The primary objective of this project is to showcase how modern AI and workflow automation tools can be combined to automate repetitive business processes without relying on paid AI services.

---

# 🚀 Business Problem

Organizations receive hundreds of emails daily containing:

- Job applications
- Customer inquiries
- Sales leads
- Partnership requests
- Support tickets
- Marketing campaigns

Manually reviewing and categorizing these emails consumes significant time and effort.

This solution automates the process by:

1. Detecting incoming emails.
2. Extracting structured information.
3. Saving the extracted data.
4. Sending notifications to relevant teams.

# 🔄 Workflow Execution

## Step 1: Gmail Trigger

The workflow continuously monitors a Gmail inbox for newly received emails.

Example:

```text
From: hr@company.com
Subject: Hiring Backend Developer
Body: We are looking for an experienced Node.js developer.
```

When a new email arrives, n8n automatically triggers the workflow.

---

## Step 2: Email Metadata Extraction

The workflow extracts essential information from the Gmail payload:

```json
{
  "From": "hr@company.com",
  "To": "candidate@gmail.com",
  "Subject": "Hiring Backend Developer",
  "snippet": "We are looking for an experienced Node.js developer"
}
```

---

## Step 3: AI-Powered Information Extraction

The extracted email content is sent to a locally hosted Qwen3 model through Ollama.

### Sample Prompt

```text
Extract lead information from this email.

Return ONLY valid JSON.

{
  "sender":"",
  "receiver":"",
  "subject":"",
  "name":"",
  "company":"",
  "email":"",
  "requirement":"",
  "priority":""
}
```

### Example AI Output

```json
{
  "sender": "ABC Technologies",
  "receiver": "mukund@gmail.com",
  "subject": "Hiring Backend Developer",
  "name": "Mukund Kumar",
  "company": "ABC Technologies",
  "email": "hr@abc.com",
  "requirement": "Node.js Developer",
  "priority": "High"
}
```

The AI converts unstructured email text into structured business data.

---

## Step 4: JSON Parsing

The response generated by Ollama is parsed into a valid JavaScript object using an n8n Code Node.

Example:

```javascript
const parsed = JSON.parse($json.response);
return [{ json: parsed }];
```

---

## Step 5: Data Persistence

The extracted information is sent to a custom Express.js API.

### Endpoint

```http
POST /api/leads
```

### Request Body

```json
{
  "sender": "ABC Technologies",
  "receiver": "mukund@gmail.com",
  "subject": "Hiring Backend Developer",
  "name": "Mukund Kumar",
  "company": "ABC Technologies",
  "email": "hr@abc.com",
  "requirement": "Node.js Developer",
  "priority": "High"
}
```

---

## Step 6: MongoDB Storage

The backend stores the lead information in MongoDB.

### Example Document

```json
{
  "_id": "6840d2d6f7b3c3",
  "sender": "ABC Technologies",
  "receiver": "mukund@gmail.com",
  "subject": "Hiring Backend Developer",
  "name": "Mukund Kumar",
  "company": "ABC Technologies",
  "email": "hr@abc.com",
  "requirement": "Node.js Developer",
  "priority": "High",
  "createdAt": "2026-06-05T09:30:00Z"
}
```

---

## Step 7: Slack Notification

After successful database insertion, the workflow sends a Slack notification.

### Sample Notification

```text
🚀 New Lead Received

Company: ABC Technologies
Contact Email: hr@abc.com
Requirement: Node.js Developer
Priority: High
```

This allows teams to react instantly to new opportunities.
